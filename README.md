## 📦 Proyectos Destacados

### 🟢 Lenguajes & Compiladores
- **[B_lang](https://github.com/BJZR/B_lang)** — Lenguaje de programación compilable (beta) a ensamblador x86_64 para Linux.
- **[MLang](https://github.com/BJZR/MLang)** — Compilador minimalista enfocado en arquitectura Linux x86_64.
- **[transpilador-c](https://github.com/BJZR/transpilador-c)** — Transpilador que procesa sintaxis personalizada hacia C estándar.

### 🔵 Sistemas & Entornos Linux
- **[ryf](https://github.com/BJZR/ryf)** — Shell minimalista y eficiente desarrollado en Go.
- **[wmp](https://github.com/BJZR/wmp)** — Gestor de ventanas híbrido y ligero basado en DWM y BSPWM.
- **[MinDE](https://github.com/BJZR/MinDE)** — Entorno de escritorio minimalista para sistemas Linux.

- **[snap](https://github.com/BJZR/snap)** — Control de versiones local ultrarrápido para flujos de trabajo eficientes.
- **[treegen](https://github.com/BJZR/treegen)** — Generador CLI de estructuras de proyectos a partir de esquemas en texto.

### 🔴 Desarrollo Web & Aplicaciones
